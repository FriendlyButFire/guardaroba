# Foto compresse al salvataggio, backup automatico Android + export ZIP

Il backup automatico di Android ha un limite di 25 MB per app, e se lo si supera il backup si ferma del tutto. Per questo ogni foto viene ridimensionata a circa 720 px sul lato lungo (WebP, ~40–60 KB) al salvataggio, e si conserva solo questa versione, scartando l'originale. Così database e foto (~400 Capi) stanno dentro il backup automatico. Oltre l'80% della quota l'app avvisa. Come rete di sicurezza c'è anche l'export/import manuale di un file ZIP; l'import sostituisce il Guardaroba dopo una conferma.

**Superato in parte:** il contenuto dello ZIP (qui "database + foto") è sostituito da [[0007-formato-export-zip]].
