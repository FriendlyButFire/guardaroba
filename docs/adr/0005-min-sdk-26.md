# minSdk 26 (Android 8.0)

L'app gira su Android 8.0 (API 26) o superiore. Da API 26 ci sono le icone adattive e `java.time` senza desugaring, e praticamente ogni telefono in uso oggi ci rientra; scendere più in basso non serve, perché l'app è per il telefono dell'utente. `targetSdk` è 36, perché Robolectric arriva al massimo a SDK 36. `compileSdk` è 37, perché `androidx.core` 1.19 lo richiede.
