# Offline, abbinamenti con regole di teoria dei colori, nessuna AI

L'app è a uso personale: i dati restano solo sul telefono e gli abbinamenti nascono da regole deterministiche di teoria dei colori codificate nell'app (neutri, monocromatico, analoghi, complementari; niente triadi, [[0004-regole-di-armonia]]), non da modelli AI o API cloud. Così non ci sono costi, chiavi API o dipendenze di rete, e il risultato è testabile. Restano fuori dalla v1 anche armocromia personale, meteo e occasione.
